# Rinkong

Sistema de reservas para hotel desarrollado en Java.

## Descripcion
Rinkong permite gestionar reservas de habitaciones utilizando Hibernate para la persistencia de datos y synchronized para controlar las reservas simultaneas y evitar el overbooking.

## Tecnologias
- Java 21
- JavaFX
- Hibernate
- PostgreSQL
- Maven
